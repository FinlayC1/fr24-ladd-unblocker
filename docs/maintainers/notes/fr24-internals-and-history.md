v22.5.0 (installed 2026-09-24): conditional-logit weights over transparent evidence terms, 108 situations (elapsed-time band x kind x height x distance), 45 features. History-first evidence with shared weights (home base, return leg, own routes both ways, going home to registration country, ocean crossing), squawk code block and FMS altitude -> trip length tables, runway fit/intercept/downwind, local arrival hour, OD pairs, bizjet usage.

Honest yardstick: test/diag_time.cjs (clock-time sampling every 12 min = random map clicks, FULL candidate list, held-out folds). v22.4.2 weights 44.4% -> v22.5.0 45.6% overall; >2 h to landing 18.8% -> 22.5%; <10 min to landing ~85%. Fraction-based numbers (95% at 97% of flight) overstate what users see.

Lessons: (1) training on the old engine's top-N candidates biased the fit (return-to-origin picks on long flights) - use sampled softmax (top-80 + uniform tail with log(N/K) offset); (2) rare evidence needs shared weights across situations or L2 holds it at 0; (3) fraction-of-flight sampling taught a short-trip bias early in flight.
