Chrome loads this extension from the folder you unzipped it into. Choose that folder once and allow Chrome to edit it. After that, updating is one click.

Not sure where it is? Open chrome://extensions (edge://extensions in Edge), find FR24 LADD Unblocker and click Details. The folder is shown next to Source.

This browser doesn't let an extension write to its own folder, so the new version has to be put in by hand:

  1. Download the new zip.
  2. Unzip it over the extension's folder, replacing the files.
  3. In the LADD Unblock window on Flightradar24, click Reload extension.
